# Feature Matrix: Privacy & Browser Intelligence Auditor

| Feature | Reference Location | Description | User-Visible | Backend-Dependent | External-Provider-Dependent | Database-Dependent | Priority | Implementation Phase | Verification Method |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Client IP Detection** | Server / TCP Connection | Extracts client IPv4/IPv6 from TCP connection or proxy headers (`X-Forwarded-For`, `CF-Connecting-IP`). | Yes | Yes | No | No | P0 | Phase 1 (Backend Core) | Call `/api/ip` and verify IP response matches client. |
| **GeoIP Intelligence** | Server / GeoIP Integration | Resolves IP to Country, City, ISP, ASN, Postal Code, Lat/Long, Timezone. | Yes | Yes | Yes (IP-API / MaxMind /ipinfo) | No | P0 | Phase 2 (IP Intelligence) | Verify response returns valid GeoIP payload for test IPs. |
| **Proxy / VPN / Hosting Detection** | Server / Security Engine | Detects if client IP originates from a datacenter, VPN provider, Tor node, or residential proxy. | Yes | Yes | Yes | No | P0 | Phase 2 (IP Intelligence) | Test with datacenter IP vs residential IP. |
| **HTTP Header Audit** | Server / Header Parser | Inspects `User-Agent`, `Sec-GPC`, `DNT`, `Accept-Language`, client hints, proxy headers. | Yes | Yes | No | No | P0 | Phase 1 (Backend Core) | Verify header breakdown table correctly flags active vs missing headers. |
| **Canvas Fingerprinting** | Client / HTML5 Canvas | Draws hidden canvas graphics & computes SHA-256/32-bit hash of rendered pixels. | Yes | No | No | No | P0 | Phase 3 (Browser Intelligence) | Verify unique hash generated across different browsers. |
| **WebGL Hardware Inspector** | Client / WebGL Extension | Queries `WEBGL_debug_renderer_info` extension for GPU Unmasked Vendor & Renderer. | Yes | No | No | No | P0 | Phase 3 (Browser Intelligence) | Verify GPU string (e.g., Apple M1 / NVIDIA RTX) displayed. |
| **AudioContext Fingerprinting** | Client / Web Audio API | Renders audio oscillator buffer & extracts frequency response audio signature hash. | Yes | No | No | No | P0 | Phase 3 (Browser Intelligence) | Verify consistent hash output across audio hardware sessions. |
| **WebRTC IP Leak Inspector** | Client / RTCPeerConnection | Creates RTCPeerConnection to STUN server & inspects ICE candidates for local/public IP leakage. | Yes | No | No (Uses STUN) | No | P0 | Phase 3 (Browser Intelligence) | Test with VPN active to check if local LAN IP is exposed. |
| **Hardware & Screen Metrics** | Client / Navigator API | Measures CPU Cores, Device Memory, Screen geometry, Color depth, Touch points. | Yes | No | No | No | P1 | Phase 3 (Browser Intelligence) | Verify screen width/height and CPU cores match device specs. |
| **Privacy Calculation Engine** | Server / Privacy Engine | Computes score (0–100) based on weighted deductions across network, headers, & fingerprint. | Yes | Yes | No | No | P0 | Phase 4 (Privacy Score Engine) | Unit test score formula with various risk combinations. |
| **Animated Radial Score Meter** | Client / UI Component | Renders animated gauge with color transitions and score tiering. | Yes | No | No | No | P0 | Phase 5 (UI Dashboard) | Verify gauge animates from 0 to final score on load. |
| **Interactive Header Breakdown** | Client / UI Component | Filterable table showing inspected headers, risk status, and descriptions. | Yes | No | No | No | P1 | Phase 5 (UI Dashboard) | Test filtering by Identity, Security, & Proxy tabs. |
| **Bilingual i18n Engine** | Client / i18n Module | Supports English (LTR) and Arabic (RTL) localization with instant toggle. | Yes | No | No | No | P0 | Phase 6 (Localization & RTL) | Toggle language and verify layout mirrors and text changes. |
| **Arabic RTL Layout Engine** | Client / Styling System | Automatically flips grid alignments, flex direction, and applies Arabic typography in RTL mode. | Yes | No | No | No | P0 | Phase 6 (Localization & RTL) | Inspect DOM `dir="rtl"` and visual layout flow. |
| **Admin Portal Auth** | Server & Client / Admin Module | Secure username/password login for administrative stats dashboard. | Yes | Yes | No | Yes | P1 | Phase 7 (Admin & Analytics) | Login with correct vs incorrect credentials. |
| **Analytics & Scan Logging** | Server & DB / Analytics Module | Stores anonymized scan metrics (score, country, proxy flag) for aggregate statistics. | No | Yes | No | Yes | P1 | Phase 7 (Admin & Analytics) | Query DB after running scans to verify recorded rows. |
| **Admin Stats Dashboard** | Client / Admin Module | Visual charts for scan volume, top countries, VPN usage percentages, and threat activity. | Yes | Yes | No | Yes | P1 | Phase 7 (Admin & Analytics) | Verify charts update dynamically with database figures. |
