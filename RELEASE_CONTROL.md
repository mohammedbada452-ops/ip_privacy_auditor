# Release Control

## Deployment contract

Cloudflare Workers Builds must use:

- Root directory: `/`
- Build command: `npm run build:cloudflare`
- Deploy command: `npx wrangler deploy`
- Preview deploy command: `npx wrangler versions upload`

The Wrangler configuration intentionally contains no custom `build.command`. Workers Builds owns the application build step; Wrangler only bundles and deploys the already-generated Worker/assets.

## Integrity guarantees

- `package-lock.json` is the source of truth for dependency installation.
- `bun.lock` is intentionally absent.
- `dist/` is generated by the Cloudflare build command and is not committed.
- No secrets belong in Git.
- PostgreSQL, Hyperdrive, Express, admin/auth routes, and existing scoring remain intact.

## Optional IP reputation

Set `ABUSEIPDB_API_KEY` as a Cloudflare Worker secret to enable `/api/ip/reputation`. The feature is informational and does not modify the canonical privacy score. Without the secret, the endpoint returns `UNAVAILABLE` rather than failing or inventing a result.
